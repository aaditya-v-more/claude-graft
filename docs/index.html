Claude Graft

Claude Desktop signs into one account at a time. Graft gives you as many Claudes as you want — each with its own name, icon and login — and lets any of them read another one's Claude Code history.

That last part is the point. Every other way of running two accounts gives you an empty second profile. Graft lets your work login open your personal chats, connectors and extensions while the accounts stay completely separate.

Install

brew install --cask aaditya-v-more/claude-graft/claude-graft

Homebrew asks you to trust the cask the first time, because this isn't an official Homebrew tap. Say yes once and it never asks again. macOS 13 or later; universal, for Apple Silicon and Intel. Or take the disk image from the releases page.

Making a Claude

Name it, choose where its chats come from, press Create Shortcut. You get a real app in /Applications that you can launch from Spotlight or pin to the Dock like any other.

What it does not do

Nothing is written back to Claude's config or keychain. Only the access token is ever read, never the refresh token — Anthropic rotates those, and using one would sign Claude Desktop out. The token goes to api.anthropic.com and nowhere else.

It also refuses to touch any application it did not create, identifying its own by a description file they carry rather than by name.

Updating

Graft updates itself, checking hourly and at launch. Every download is verified against a signing key that ships inside the app; anything that doesn't match is refused.
