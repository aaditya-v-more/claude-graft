Clearer account controls and more personal shortcuts

The Claude Desktop update bar now has its own space above the account list and profile controls. The first account and the top of each form stay visible, including in smaller windows.

Choose a colour or a Work, Personal, Code or Research icon for each shortcut to make accounts easier to tell apart. The app also includes Russian localization, including update warnings, recovery messages and account controls. Fable usage appears when the account reports a separate limit.

Updating a shortcut now prepares and verifies the replacement before changing the installed app. If preparation fails, the existing shortcut stays usable, including when the update would rename it.

Upgrading from 1.0.x

As with 1.1.0, shared profiles merge their chat histories on their next launch. Going back to a profile's own chats preserves what it brought, but copies already merged into the source stay there. If you need an untouched copy, back up your Claude profile folders in ~/Library/Application Support before upgrading.
