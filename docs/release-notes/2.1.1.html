Claude Graft for Windows

Claude Graft now has a Windows version, released from this repository and numbered with the Mac's. It does what the Mac app does from the notification area instead of the menu bar: Claudes side by side with their own sign-ins, shared Claude Code history, pins and project order, usage for every account, shared usage, and the Artifacts, Projects and Search Chats panes. It finds the Microsoft Store version of Claude as well as the one from claude.ai, sends a Claude sign-in back to the profile that started it, and installs and updates itself. It comes from two community ports brought together, by Tyler and James.

Download ClaudeGraftApp-win-Setup.exe from the release and run it. An earlier Windows build from the original Windows repository can be updated by running the same setup over it.

On the Mac

Nothing changes on the Mac with this release: the Mac app stays on 2.0.1 until its next version, which joins this line.

Upgrading from 1.0.x

As with 1.1.0, shared profiles merge their chat histories on their next launch. Going back to a profile's own chats preserves what it brought, but copies already merged into the source stay there. If you need an untouched copy, back up your Claude profile folders in ~/Library/Application Support before upgrading.
