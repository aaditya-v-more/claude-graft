Your sidebar comes with you

Switching accounts shouldn't mean rebuilding your pinned list. Profiles that share Claude Code chats now keep their pins, pinned order and Code sort choice in sync. Unpin a chat in either profile and it stays unpinned in the other.

To sync the sidebar, quit the linked Claude apps, then open either shortcut. If one is still open, Graft waits until the next opening and tells you what to close. Other chats, custom groups and account settings stay as they were.

That weird transparent bar over the shortcut settings on macOS 27 is gone. The name and profile controls are clickable again. Shared profiles also keep their own permission choices, so sharing chats no longer replaces the settings you picked in Claude. Missing local MCP server definitions can still be copied over; existing server settings stay yours.

Tested with Claude Desktop 2.110.1 on macOS 27, including real restarts, two-way pin and sort changes, and clearing the last pin. Still universal for Apple Silicon and Intel, with macOS 13 or later supported.

Coming from 1.0.x?

Shared profiles merge their chat histories on the next launch. Switching back to a profile's own chats keeps what it brought, but copies already merged into the source stay there. If you want an untouched copy, back up your Claude profile folders in ~/Library/Application Support before updating.
