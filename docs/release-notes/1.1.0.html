Sharing a history now merges it

Until now, pointing one profile at another's chats replaced its own. Your conversations went into a hidden folder beside them and the other profile's stood in their place, and a profile sharing chats this way could not archive, rename or delete any of them — Claude will not write a record into a folder that lives outside the profile.

From this version the folder is real and the two histories are merged, so both sidebars hold both sets and a shared profile behaves like a profile again.

Worth reading before you install this one

Merging cannot be undone. The first launch after updating copies each sharing profile's conversations into the profile it borrows from. Sending it back to its own chats afterwards gives back everything it started with, but the copies stay where they were merged.

Take a copy first if that matters to you. Every profile lives in ~/Library/Application Support; copying the Claude folders somewhere safe is the whole backup, and it takes a minute.

Nothing is thrown away on the way. What each profile brought to the merge is kept in a hidden folder beside its chats, which is what going back reads from. And if a conversation does go missing, it is almost always still on disk: the transcripts are in ~/.claude/projects, and Graft files a record back for any session that lost one.

This is the only update that will ask. Later ones install themselves quietly, the way they always have.
