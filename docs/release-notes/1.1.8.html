See which Claude you are using

Every running Claude shows Claude's own name and icon in the Dock, so it was hard to tell which account was in front. The menu bar now shows it instead: while a Claude is in front, Graft's icon in the menu bar carries that shortcut's icon beside that account's usage. You can add its name in Settings, or turn either off.

Usage figures now say when they were taken and where they came from, and each account has its own refresh button. An open Claude's account is checked more often, bringing a Claude to the front refreshes it, and Refresh Usage now always asks for a new figure.

A conversation you edited, retried or resumed no longer shows up several times in a shared sidebar, and a chat you forked keeps both halves.

Every control now works with VoiceOver and says which account it acts on, and the Claude update line at the top takes less room.

Works on Apple Silicon and Intel, with macOS 13 or later supported.
