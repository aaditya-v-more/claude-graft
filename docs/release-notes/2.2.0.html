A chat two Claudes both carried on becomes two

When two Claudes sharing chats both went on with the same chat between two syncs, each carried it into a conversation of its own, and only one of them stayed in the sidebars; the other was left on disk with nothing naming it. Now the chat becomes two in every Claude sharing it, each half named after the Claude that carried it on, such as “Plans (Claude)” and “Plans (Work)”, and each opening on its own last reply. The split waits until both Claudes have quit, because a Claude that is open would write its half back over it.

Archived chats stay archived

A chat archived in one Claude no longer comes back in the Claudes sharing it, and one brought back in either stays brought back. What two Claudes change in the same chat between syncs is now merged field by field, rather than one side's record winning whole.

Less work in the menu bar

The conversation running across the menu bar now moves on a layer of its own instead of being redrawn several times a second, so Graft does far less while a title runs, and nothing while a short one stands still. It moves exactly as before.

Donate

The tip jar is now Donate, with a red heart, in the sidebar, the dropdown and the Help menu, as on Windows. Help opens the site at its own address, graft.aadityamore.com.

Also fixed on the Mac

  • Every new Claude gets a profile folder no other Claude uses, also while its name is being typed, and a new Claude given an existing one's name no longer takes over its app, so Open, Start Session and Delete reach the right account.
  • Deleting an open Claude's profile is refused before anything is removed, so its folder is never left half gone.
  • A conversation that made an artifact can still move between accounts under Shared usage.
  • Project headings keep the same order in Claudes on different accounts sharing a history, and chats outside any project stay under This computer in every Claude they reach. Going back to a Claude's own chats hands those back too.
  • A project order write that fails partway is put back in every Claude it reached, a stored project-order time too large to read no longer stops a sync, and a Claude opened from the Dock while Graft carries project order after a quit opens normally.
  • The dropdown stays on screen however many accounts there are; the account list scrolls instead.
  • A new Claude's folder box shows the whole folder, and Donate and Source stay whole at the foot of the sidebar, one above the other where they can't sit side by side.

With fixes from Christofu450, Juulsn and PvtLight.

Upgrading from 1.0.x

As with 1.1.0, shared profiles merge their chat histories on their next launch. Going back to a profile's own chats preserves what it brought, but copies already merged into the source stay there. If you need an untouched copy, back up your Claude profile folders in ~/Library/Application Support before upgrading.
