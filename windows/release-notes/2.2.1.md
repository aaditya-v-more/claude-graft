Claude Graft 2.2.1 fixes a Mac problem: with a long shared chat history, Graft could run out of memory. Nothing changes on Windows; the number moves with the Mac's so both stay on one version.

## Upgrading

Graft 2.2.0 updates itself to this release. To install it fresh, download `ClaudeGraftApp-win-Setup.exe` from this release and run it; running it over an earlier install updates that install.
