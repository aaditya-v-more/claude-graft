Claude Graft 2.3.0 is mostly a Mac release: accounts get a page of their own there, with an order and automatic sessions. On Windows it makes sidebar sync safer and does less work in the background.

## Upgrading

Graft 2.2.0 updates itself to this release. To install it fresh, download `ClaudeGraftApp-win-Setup.exe` from this release and run it; running it over an earlier install updates that install.

## Fixed

- Sidebar sync is skipped when Graft's helper and Claude are on different major versions of Electron, so a newer one cannot leave Claude's sidebar in a form Claude cannot read.
- With nothing to sync, Graft no longer rewrites its record of shared chats or reads every chat again on every pass.

The Accounts page, Auto-start and the choice of organization are on the Mac only for now.
