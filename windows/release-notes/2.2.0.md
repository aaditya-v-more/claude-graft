Claude Graft 2.2.0 brings the Windows app to Russian, asks before a second Claude opens on the same chats, and keeps Start hidden to the launch at sign-in. The Mac app joins this version line with the same release.

## Upgrading

Graft 2.1.1 updates itself to this release. To install it fresh, download `ClaudeGraftApp-win-Setup.exe` from this release and run it; running it over an earlier install updates that install.

## New

**Russian.** Graft speaks Russian when Windows' display language is Russian, and English otherwise.

**A question before a second Claude opens on the same chats.** Opening a Claude while another Claude on the same chats is open asks first, from the window, the flyout and the notification-area menu, as the Mac does.

**Help and feedback in Settings:** the site, what's new, a problem report on GitHub, and an email that already carries your Graft and Windows versions.

**Recovered sessions named.** When Graft files a Claude Code session that had gone missing from Claude's sidebar, the flyout says which. Graft also makes that pass when it starts and when the flyout opens.

**The icon and the name of the Claude in front** switch on and off separately on the taskbar.

## Fixed

- Start hidden keeps only the launch at sign-in out of sight. Opening Graft from Start or a shortcut while it runs hidden always shows its window, in front of the others.
- Every new Claude gets a folder and a name no other Claude has.
- Removing an open Claude together with its data is refused before anything is removed.
- A conversation that made an artifact can still move between accounts under Shared usage.
- The Claude update button in the sidebar moves under the Claude's name when beside it the name would break.
